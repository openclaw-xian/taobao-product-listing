# 素材包样例（**地毯类目专用**，不是通用模板）

这是**一份能直接被技能读通的素材包**——从真实素材包里抽掉商品数据、只留结构和 2 行示例做出来的。
用途是让你看到"能被技能读懂的东西长什么样"，**不是**"改改就能用在别的类目"。

> ## ⚠️ 每个类目的素材包都不一样，别拿它套别的类目
>
> 实测三个类目（三个都是真跑通过的包），结构差异如下：
>
> | | 地毯 `50000582`（就是这个样例） | 猫抓板 `50003280` | 自贴墙纸 `201802801` |
> |---|---|---|---|
> | 属性列 | 19 个：表面材质 / 产地 / 省份 / 货号 / 品牌 / 型号 / 上市年份季节 / 主图案类型 / 编织工艺 / 风格 / 可定制性 / 适用空间 / 售卖方式 / 防滑等级 / 清洗类型 / 适用场景 / 吸音性能 / 形状 / 是否定制 | 18 个：品牌 / 型号 / 主体材质 / 安全认证 / 包装规格 / 表面涂层材质 / 层数结构 / 多猫承载量 / 核心功能 / 环保认证 / 货号 / 可替换内芯 / 展开长度 / 展开宽度 / 折叠后厚度 / 支撑结构 / 重量 / 适用猫体型 | 15 个：品牌 / 货号 / 计价单位 / 宝贝类型 / 采购地 / 库存类型 / 功能 / 适用空间 / 风格 / 是否定制 / 图案 / 材质 / 面层工艺 / 发货时间 |
> | 规格维度列 | `地毯尺寸` | **没有尺寸列**：多猫承载量 / 展开长度 / 展开宽度 / 折叠后厚度 / 重量 | 无独立尺寸列 |
> | 规格层数 | **两层**（颜色 × 地毯尺寸） | **单层**（尺寸并进「颜色分类」） | 4 色 × 4 款式 |
> | 必填属性 | 6 个 | 3 个 | **0 个** |
> | R4 元数据列数 | 42 | 44 | — |
> | 含哪些平台 sheet | 只有 `淘宝` | `淘宝` + **`拼多多`** | — |
>
> 注意连"材质"这个字段三个类目都不同名：`表面材质` / `主体材质` / `材质`。
>
> **所以：换类目时 R2（属性列）、R3（规格列）、R4（元数据）必须整行换成你那个类目的，
> 只改 R1 的类目名一定跑歪**——属性填不上，或者规格层数错（单层包按两层填、两层包按单层填）。
>
> 素材包由你自己的选品/上架工具**按类目**生成；技能只消费，不生成。拿到新类目的包之后，
> 先跑一次 `-DryRun` 看它读出了什么（见第五节），别直接正式跑。

## 一、目录长这样

```
素材包模板\
  商品信息.xlsx                 ← 一个 Excel，4 张 sheet
  淘宝\
    示例商品A-01\                ← 目录名 = 商品标识，两者必须完全一致
      1比1主图\                  ★必传，比例 1:1，建议 1440x1440 以上，至多 5 张
      3比4主图\                  选传（技能按口径不传 3:4）
      宝贝详情\                  ★必传，建议 01、02、03 编号，每批最多 20 张
      规格图片\                  选传，每个颜色一张
      SKU搜索主图\               选传
      商品视频\                  选传（技能不传视频）
      白底图\                    选传
```

`淘宝\<商品标识>\` 里**只放图片**（jpg/jpeg/png/webp），说明文件不会被算进张数。

## 二、Excel 的结构（4 张 sheet）

| sheet | 作用 |
|---|---|
| `填写说明` | 平台自带的填写说明，保留即可 |
| `素材包设置` | 素材包根目录（B6）+ 7 个素材目录的必传要求清单 |
| `淘宝` | **技能真正读的那张** |
| `选项_taobao` | 该商品各属性在平台上的可选值，供你填属性时对照 |

`淘宝` sheet 的行结构（**行号是硬约定，别插行**）：

| 行 | 内容 |
|---|---|
| R1 | 首个单元格 = `淘宝 \| platform=taobao \| 类目 > 子类目 \| cateId=xxxxx`，技能从这里读类目来源 |
| R2 | **商品级属性列名**（就是淘宝发布页上的属性名，`★` 前缀表示必填） |
| R3 | **SKU 规格列名**（`颜色分类`、`地毯尺寸`、`价格`、`数量`、`商家编码`、`规格图片文件名`…） |
| R4 | 每列一个 **JSON 元数据**（`key` / `required` / `parentKey=sku` / `kind` / `numeric`），技能靠它判定哪些是属性、哪些是 SKU 维度、哪些必填 |
| R5 起 | **商品数据**。第一个数据行填商品级字段（商品标识、标题、属性、一口价），后续行只填 SKU 级字段 |

技能视角的必填/可选（以真实跑通为准）：

- **SKU 必填**：`颜色分类`、`价格`、`数量`
- **SKU 可选**：`地毯尺寸`（或 `款式`/`尺寸`/`尺码`/`规格`——列名各版本不同，技能都会认）、`商家编码`、`规格图片文件名`、`SKU搜索主图文件名`
- **商品级**：`商品标识`、`宝贝标题`；属性列按类目必填（`★` 那几个）

## 三、几个必须知道的口径

1. **商品标识 = 目录名**。不一致时技能以目录名为准，并给你一条警告；目录名才是权威。
2. **一口价必须等于某个有库存 SKU 的价格**。技能默认取最低 SKU 价，想指定就传 `-ListPrice`；
   给一个不在价格集合里的数会被平台拦。
3. **规格图片文件名**填**文件名**（如 `规格图-米白.jpg`），不要填路径；要跟 `规格图片\` 目录里的文件完全一致。
4. **颜色值是长营销文案也可以**（例如 `消音降噪⭐米白【消音率99%⭐ 防溅水防暴晒】`）。
   这种值做不了文件名，所以靠 `规格图片文件名` 列做显式映射，技能不会去猜"文件名包含颜色名"。
5. **两层规格还是单层，看类目**。地毯是 `颜色分类 × 地毯尺寸` 两层；猫抓板那类没有独立尺寸列，
   两维并进 `颜色分类`（单层）。技能两种都处理，但**素材包要按你类目实际来**，别硬拼。
6. **多值用英文逗号**（如 `阳台,户外`）。

## 四、最小验证方法（不碰店铺）

```powershell
& "<技能>\scripts\run_listing.ps1" -Pack "<你的素材包>" -CatId <catId> -Cat "<类目路径>" -DryRun
```

`-DryRun` 只跑数据管道 + 打印计划，**不开页面、不点任何按钮**。它会告诉你：商品号、
SKU 行数、价格档、一口价取了多少、各目录图片张数、规格图映射缺几个、以及 15~18 步的计划。
这一步绿了再去掉 `-DryRun` 正式跑。

## 五、模板本身是怎么验过的

拿本模板自己当输入跑过一遍 `-Pack -DryRun`：

```text
① 淘宝 sheet：2 行
③ SKU 共 2 行 | 颜色 1 种 | 款式 2 种 | 价格档 2 个：[18.8, 22.8]
一口价未传 → 取最低 SKU 价 18.8
① 拷图：1比1主图 0 / 宝贝详情 0（目录里只有说明文件，不误算成图）
```

即"结构能被解析、价格能被读到、说明文件不污染张数"。它**没有图**，所以正式跑会跳过图片步骤——
你填自己的图之后才会有图。
