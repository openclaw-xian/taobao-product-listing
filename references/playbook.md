> **这份是 2026-10 那次成功上架（ZDT-003 自粘地毯 → 商品ID 1085292649663）时逐步记下来的现场笔记。**

>
> ⚠️ **它不是保证**：淘宝发布页改版频繁，选择器会变。**一切以现场 DOM 为准**（`SKILL.md` 门禁 3），

素材库位置：`D:\wps云文档\...\本地图片素材库\AI\accio+jst\<素材包>\`（数据在 `发品excel\<商品号>.xlsx`）。

> 路径注意：WPS 云盘路径含特殊字符（Unicode 细空格 `\u2005`），PowerShell `Test-Path` 手拼常失败 ——

## 2. 操作前：先关弹窗（门禁 4）

用户多次提醒。每步前：

1. 关图片预览 lightbox（右上角 X，常在 x>1780, y<200）
2. 处理「切换展示模式将清空当前数据」等对话框（确认切换 / 取消）
3. 再点业务控件

**不要随意 Escape** —— 会关掉正在用的规格抽屉。

## 3. 类目（入口固定「搜索发品」）

**唯一入口 = 搜索发品** —— `https://item.upload.taobao.com/sell/ai/category.htm` 左侧那张卡片。
**不要走「以图发品」**：实测它会把上传的主图**自动铺进「宝贝详情图」**，与我们「主图 5 张 / 详情 20 张各自独立」
的口径冲突，最后要先删再铺、更费事（用户 2026-10-10 拍板弃用，门禁 19）。

步骤（现状，2026-10-10 实测）：

1. 打开 `category.htm` → 「搜索发品」卡片现在**直接就是** 搜索框 + 发布历史 + **类目级联树**（没有「开启」按钮）
2. **在级联树里按素材包给的完整路径逐级点** `li.category-item`（`mousedown`+`mouseup`+`click`，`el.click()` 无效）：
   `宠物/宠物食品及用品` → `猫/狗玩具` → `猫抓板` → 三级都 `selected`、底部显示路径
   （**不用** AI 推荐 / 搜索推荐 —— 门禁 19）
3. **在本页选品牌**：点「请输入」→ 弹层 `.sell-o-select-options` → **用它自带的搜索框**输入品牌名过滤
   → 点命中的 `div.options-item`（门禁 20）
4. 点「**确认，下一步**」→ 进入 `publish.htm?catId=<catId>&fromAICategory=true`

读回口径：URL 里有 `catId`，且表单「当前类目」文本 == 素材包路径（`>>` 分隔）、品牌 == 目标值。

> 历史写法（旧版入口页）：搜索框输入关键词 → **回车**（点「搜索」按钮无效）→ 点类目推荐行 → 级联定位 → 提交叶子。
> 现在级联树就在同一张卡片里，**直接按路径点更稳**，不必依赖搜索。

## 4. 1:1 主图（门禁 5）

- 页面 **没有** `input[type=file]`
- 点空位 → 图片空间 iframe `sucai-selector-ng`
- iframe 内「本地上传」触发 filechooser
- `realTimeSelect` / `max=1`：一次选一张填一个槽
- 顺序调整：普通拖拽无效；可用 React：
  `el.__reactEventHandlers$*.onDragStart/onDrop`（fiber 上 `we`/`Ie`）
- 正确 CDN 匹配用 `O1CNxxxx` id，不要只比 querystring

## 5. 分层规格（SKU）

- 推荐 **分层展示**：`颜色分类` + `地毯尺寸`
- 颜色分类主色 **可填自定义**（如「卡其色-2片」）
- 尺寸 **顺序必须 30→40→50→60**（用户明确要求）
- 尺寸框是 combobox：输入后可能要点放大镜；无下拉项时 ArrowDown+Enter
- 每个规格值提交后点该区块 **`button.add`** 才能出下一行
- 「确认创建」后生成多层 SKU 表（实测 72 = 18 色包 × 4 尺寸）

## 6. SKU 表填写

虚拟滚动容器：`.ver-scroll-wrap`（横向 `scrollLeft` 常在右侧，**先归零**）。

| 字段 | 说明 |
|------|------|
| 价格 | 按 Excel；setter + input 事件 |
| 库存 | 常 999 |
| 商家编码 | 表内 setter 不稳定；**用「去填写」弹窗写入并点确定** 更稳 |
| SKU搜索主图 | 见 §7 |

**一口价（门禁 6，硬约束）**：必须等于「有库存 SKU 价格之一」。

> 错误提示原文：`商品"一口价"必须与"商品销售规格"列表里有库存的sku其中之一保持一致`
> 可填 13.60 / 16.40 / 19.00 等（实测值）；填 83 会报「一口价填写错误」（因为 SKU 里没有 83）。

## 7. SKU 搜索主图（批量，门禁 10）

流程（用户确认有效）：

1. 横向滚到 SKU 表左侧，点 **空的** `sell-sku-cell-image` → 打开 **「批量填充SKU搜索主图」**
2. 右侧选中 SKU（`li.sku-item`）
3. 左侧搜索框输入 `颜色-尺寸`（如 `卡其色-30x30cm`）
4. **必须点放大镜** `i[aria-label="搜索"]` / `.next-search-icon`
5. Playwright 点击匹配的 `PicList_pic_background` 里的 img
6. 重复直至 `N/72`
7. 点「确定」

> ⚠️「上传素材」按钮是 **放我家 / 3D 关联**，不是搜索主图。

## 7.5 颜色分类规格图（添加图片，门禁 11）

分层展示的颜色分类可勾选「添加图片」，每个颜色行（如 `卡其色-2片`）可挂规格图。

**命名必须详细**，否则与 SKU 搜索主图混淆：

```
猫抓布规格图-卡其色.jpg
猫抓布规格图-巧克力棕.jpg
猫抓布规格图-深蓝色.jpg
猫抓布规格图-米白色.jpg
猫抓布规格图-麻岩灰.jpg
猫抓布规格图-黑色.jpg
```

不要只写「卡其色.jpg」—— 搜索时会撞上 `sku-猫抓布-卡其色-30x30cm`。

**上传流程**

1. 编辑规格 → 分层展示 → 颜色分类 + 添加图片勾上
2. 点颜色行左侧空位 → 打开「批量填充规格主图」
3. **先检查左侧是否在「上传素材」面板** —— 若是，先「本地上传」全部规格图
4. 右侧选中未填图的销售属性值（可多选同色）
5. 左侧搜索 `猫抓布规格图-<颜色>` → 点放大镜 → 点对应图
6. 同色多规格（2/5/10 片）共用同一张颜色图
7. 全部填完点「确定」，再「确认创建」

**注意**

- 偶尔会跳回上传面板，要检查图是否已在空间
- 点图后不一定立刻回显，确认创建后再打开抽屉核对
- 同色 2/5/10 片都要各自填上图

## 8. 商品属性（门禁 12）

用 **字段 ID** 精确定位：

| 属性 | ID | 填法 |
|------|-----|------|
| 表面材质 | `sell-field-p-20021` | select，选「聚酯纤维」；`input.value` 可能残留，要**下拉真点选项**，确认 `em`/文案含该值 |
| 编织工艺 | `sell-field-p-9228691` | **checkbox/多选**，选「机织」 |
| 风格 | `sell-field-p-20608` | select，下拉需 **滚 `.options-content`** 才见「日式」 |
| 可定制性 | `sell-field-p-552922865` | select「不支持定制」 |
| 适用空间 | `sell-field-p-1626518` | **checkbox/多选**，选「办公室」 |
| 售卖方式 | `sell-field-p-10158998` | select「按件」 |
| 货号 / 品牌 | 常规 input | `00008` / `祺讯` |

属性多为三列网格，**label 与 input 不在同一水平线** → 按 `sell-field` id 找，不要只按「y 相近」。

> 上面的 ID 是 **ZDT-003 那次（地毯类目）** 的实测值；换类目要重新取（页面里搜 `sell-field-p-`）。

## 9. 宝贝详情（门禁 13）

1. 定位 `[class*="add_title"]`「添加」→ `[class*="add_item"]`「图片」
2. 打开的也是 **图片空间 iframe**（不是原生 filechooser）
3. 「本地上传」全量详情图（实测 40 张）
4. 「全部图片」列表里按文件名搜索、逐张点击
5. 点 iframe 内 **「确定（N）」**（`Footer_selec...`）
6. 确认 `lite-decoration-editor` 内 img 数量

一次选不全就分批：添加 → 图片 → 选 → 确定。

## 12. 与拼多多 / 抖店的差异

| 项 | 拼多多 | 抖店 | 淘宝 |
|----|--------|------|------|
| 发布页 | mms.pinduoduo.com | fxg.jinritemai.com/ffa/g/create | item.upload.taobao.com |
| 主图上传 | 常有 file input | 文件选择器 | 图片空间 iframe + 本地上传 |
| 规格 | 规格名直接填 | Excel 智能识别 | 分层 属性 / 单层 自定义 |
| 一口价 | 较少强约束 | 售卖价 | **必须等于某有库存 SKU 价** |
| 详情 | file input | 文件选择器 | 添加 → 图片 → iframe 确定(N) |
| 提交 | 提交并上架 | 发布商品 | 提交宝贝信息 |

## 13. 已知坑（都进 SKILL.md 排错表了）

| 坑 | 处理 |
|----|------|
| 无 file input | 图片空间本地上传 |
| 搜索不生效 | 点放大镜 |
| 批量框右侧选不中 | Playwright 点 `li.sku-item` |
| 尺寸/属性下拉看不到项 | 滚 `.options-content` / `.options-item` |
| 表内商家编码写完被清 | 「去填写」弹窗保存 |
| 一口价任意数 | 必须匹配有库存 SKU 价 |
| 虚拟表只显示部分行 | `.ver-scroll-wrap` 滚屏再填 |
| 弹窗干扰 | 先关 lightbox / 确认框 |
| skill 与页面不符 | **以页面 DOM 为准** |
